## 1. Основни понятия: Програмиране с Java, алгоритъм, среда за разработка (IDE), компилация и интерпретация.
### 1.1 Програмиране
Програмирането е процесът на създаване на компютърни програми. На този етап, като програмисти, ролята ни в този процес е да пишем код, постредством среда за разработка, който да бъде компилиран или интерпретиран, за да достигне до изпълнима програма. Функцията на тези програми е да решават задачи от ежедневието ни.
### Пример 1.1
```java
    public static void main(String[] args) {
        System.out.println("Hello everyone");
    }
```
Този програмен код решава задачата "Как да кажа "Hello everyone" посредством компютърен код?".

Ето един по-практичен пример
### Пример 1.2
```java
    static Scanner scanner = new Scanner(System.in);
    
    public static void main(String[] args) {
        int myNumber, myOtherNumber;

        System.out.println("Enter 2 numbers");

        myNumber = scanner.nextInt();
        myOtherNumber = scanner.nextInt();

        int sum = myNumber + myOtherNumber;

        System.out.println("The sum of the numbers is: " + sum);
    }
```

Може да се ориентирате, че програмирането на Java до една степен се чете като прост текст на английски език. Преди да обясним какво прави горния код, пробвайте се сами да отгатнете.

Пример 1.2 решава задачата "Как да събирам 2 цели числа чрез програмен код?". В последствие ще обясним как работи този код, защо го пишем по този начин, и ще разберете как да създавате такива решения, а и по-сложни, сами.
### Как работи компютъра
Няма да навлизаме в детайлите на сложните процеси, които комютрите извършват за да изпълняват нашите инструкции. Основния проблем, който програмните езици решават, е не можем да кажем на компютъра "Събери тези две числа". Нужно е да сме по-конкретни. Компютърът знае само и единствено как да разчита машинен код (нули и единици).

### Програмни езици; Компилатори и интерпретатори
В горните примери видяхме как можем да превърнем изречението "Събери тези две числа" в по-сложно и конкретно формулиран списът от инструкции за нашият компютър. Но това не е машинен код. Това се нарича програмен език. Освен Java съществуват и много други. Най-известни са Python, C, C++, Rust, JavaScript и други. Всеки от тези езици се нуждае от съответния компилатор или интерпретатор, който да превърне нашият програмен код в машинен.

Компилираните езици, на кратко, посредством компилатор, директно биват превръщани в машинен код, който компютрите ни разчитат и изпълняват. 

Интерпретираните езици биват разчетени от интерпретатор, който от своя страна казва ред под ред на компютъра какво да прави. Тези абстракни концепции могат лесно да бъдат разбрани чрез прост пример.

### Пример 1.4
Задачата ни е следната. Имаме книга, която е на френски, но ние не говорим френски. Искаме да я прочетем. Съществуват два отделни подхода, всеки със своите предимства и недостатъци.

#### Компилаторския подход
Можем да платим на френски преводач, който да ни изготви копие на български език. Това ще му отнеме няколко месеца, но сега всеки път щом искаме да прочетем книгата, тя е готова и преведена. Проблемът е, че цялостен превод е доста времеемко нещо, но веднъж щом се свърши, притежаваме книгата в ръцете си на готов и четим език.

#### Интерпретаторския подод

Вместо да плащаме на преводач, който да ни изготви веднъж превода, всеки път, щом желаем да прочетем нещо от книгата, му звъним. И той започва да чете и да ни превежда каквото ни е нужно. Положителната страна на това е, че не трябва да чакаме няколко месеца за пълния превод, но очевдния минус е, че се нуждаем от преводащ всеки път, щом ни се чете.
### Езикът Java
Java е така нареченият "Статично типизиран обектно-ориентиран език". Отностно дали е компилиран или интерпретиран: Преработката на разбираемият код, който пишем, се случва на два етапа. Посредством Java компилатора, кодът ни се превръща в нещо като машинен код, който се предоставя на JVM (Java Virtual Machine - Java виртуална машина), която от своя страна го разчита и превръща в истински машинен код, който се изпълнява директно от компютъра. Този подход се счита за хибриден - хем компилиран език, хем интерпретиран.
### Среда за разработка (IDE - Integrated Development Environment)
Средата за разработка е софтуер, който ни предоставя всички нужни инструменти за програмиране.  Примерно, за да започнем да работим на Java се нуждаем от програма, в която да пишем своя код, програма, която да го компилира и програма, която да го дава на JVM за изпълнение. Съществуват среди, които комбинират всичко нужно, наречени IDE. Примери за таква са IntelliJ, Eclipse, VisualStudio, VisualStudio Code и други. В часовете по УвП ще работим с Eclipse. Основна примерна програма


Този ред код общо взето казва на компилатора къде се намира файла, в който работите. В този курс няма да му обръщаме внимание, тъй като той най-често се генерира автоматично, при създаване на файл, от IDE-то, в което работите.

Всеки език за програмиране е съставен от така наречените *ключови думи*, каквато е и **Class**. Всичкият код, който изпълнява някаква функция в Java, бива написан в Клас.  Отново, както с package, няма да навлизаме в детайли какво точно представлява и за какво служи. Само знайте, че всяка ваша програма ще започва по този начин. По този начин се дефинира метод в езика Java. Всеки метод трябва да е написан в тялото на клас. Няма да навлизаме в детайли в момента как и защо се дефинират методи. Запомнете, че всеки метод си има име и в един клас не може да има 2 метода с едно и също такова. И освен това този метод тук е специален. ## Оператори
Един оператор, както може да се досетите, извъшва операция. Например оператора "+" извършва събиране между 2 числа. Оператора "*" извръшва умножение. Имаме дадената програма

```java
package my_package;

class MyClass {
    public static void main(String[] args) {
        System.out.println(5 + 5);
        System.out.println(5 * 5);
        5 + 5;
    }
}
```

Какво ще изпринтира този код?

Изход:
```java
10
25
```
Операторът "+", освен за събиране на числа, може да се използва и за долепяне на символни низове (текст). Например кодът
```java
System.out.println("Hello " + "everyone");
```
ще долепи "Hello " до "everyone" и ще даде изход
```
Hello everyone
```

### Променливи и типове.
За да пишем смислени програми ни е нужен начин, по който да складираме данни на компютъра, по време на изпълнението на нашата програма. Например, ако искаме програма, която събира 2 числа може да напишем

### Пример 2.2
```java
package my_package;

class MyClass {
    public static void main(String[] args) {
        int moetaPromenliva = 5;
        int moetaDrugaPromenliva = 62;

        int sbor = moetaPromenliva + moetaDrugaPromenliva;

        System.out.println("Sborut e: " + sbor);
    }
}
```
по този начин ние можем да декларираме *променливи* и да им задаваме *стойности*. В общия случай шаблона е следния:
```
    <тип> <име> = <стойност>
```
В Пример 2.2 имаме 3 променливи: 
```java
int moetaPromenliva = 5;
int moetaDrugaPromenliva = 62;
int sbor = moetaPromenliva + moetaDrugaPromenliva;
```
Те всичките са тип **int**, което идва от английското **Integer** и означава *цяло число*. Естествено съществуат и много други типове. Ето списък с **примитивните** типове, които ще използваме:

1. **int, long**  - целочислени типове. **int** променливите могат да съдържат числа в интервала
$$[-2^{31}+1, 2^{31}-1]$$
а пък тип **long** могат да съдържат цели числа в интервала

$$[-2^{63}+1, 2^{63}-1]$$
2. **float, Double** - дробни типове. Различават се отново по размера на променливите. Декларират се по следния начин
```java
double moetoDrobnoChislo = 6.7; 
double moetoNEDrobnoChislo = 5; 
```
както виждате можем да придадем целочислена стойност на променлива от дробен тип, тъй като ни е ясно, че всяко цяло число в частност е и реално (има дробна част). Обаче обратното не е вярно. Кодът
```java
int moetoCyaloChislo = 5.5;
```
не е валиден код на Java.

3. **String** - тип символен низ (текст). Изразът от Пример 2.1, "Hello World!", е пример за символен низ, съответно неговата стойност може да бъде запазена в така променлива
```java
String zdrastiTekst = "Hello World!";
```
Елементарно влече, че ако имаме две такива променливи, можем да конкатенираме (долепим) стойностите им чрез оператора "+". Кодът
```java
String text1 = "Hello ";
String text2 = "World!";

String result =  text1 + text2;

System.out.println(result);
```
ще изпринтира
```
Hello world!
```

4. **char** - тип символ. Използва се за складиране на единствен символ. Декларира се по следния начин
```java
char myCharacter = '5';
```
Може да забележите, че символите използват единични кавички ( ' ), a символните низове използват двойни ( " ).

5. **boolean**. Това е тип промелива, която може да заема една от две стойности - **true** или **false**, съответно вярно или грешно. Нейната функция ще разгледаме по-нататък. Декларира се по следния начин
```java
boolean myFalseVariable = false;
boolean myTrueVariable = true;
```
Стойностите на променливите, както видяхте в Пример 2.2, могат да се изпринтират. Достатъчно е да поставим името на променливата в скобичките на метода System.out.println
```java
int myInt = 5;
String myString = "Hello, String!";

System.out.println(myInt);
System.out.println(myString);
```

### Различните оператори
Освен + и * имаме и други оператори, с които можем да боравим. Ето някои от тях:

1. "+" - Събиране на 2 числа, долепяне на 2 символни низа.
2. "*" - Умножение.
3. "-" - Изваждане
4. "/" - Деление. Деленето се извършва по различен начин, в зависимост от вида на числата, които се опитваме да делим. Например кода
```java
5 / 3
```
5. "%" - Деление с остатък. Оператора работи само и единствено с цели числа и връща остатъка от тяхното делене. Например
```java
5 % 3
```
ще върне 2, тъй като 5 делено на 3 е равно на 1, с остатък 2.

Тези оператори се наричат числени, тъй като работят с числа по стандартните правила за аритметичните операции. Освен това имаме логически и побитови оператори, които ще разгледаме по-нататък.

### Видове изрази. Числени, логически и текстови изрази.

Всеки израз в Java си има тип, който бива определен от какъв резултат произвежда. Това е малко по-абстрактна идея, но с няколко примера ще стане ясна. Например израза
```java

```

```java

```
е от дробен тип, тъй като резултата е дроб.
